Rules that decide close calls

If the stem says…Then
Needed once (one log, one investigation)@path in the prompt. Not CLAUDE.md, not a rules file.
Team needs it, but each person has their own tokenStill .mcp.json, with ${VAR} for the token. The token doesn't make the server personal.
Shared config works for everyone but one personFix that person's environment (set the variable). Don't copy the server into their ~/.claude.json.
My own variant of a team skill~/.claude/skills/ under a different name. Same name → the personal one runs in your sessions instead of the team's.
Personal notes for one repo onlyCLAUDE.local.md. ~/.claude/CLAUDE.md also loads in every other repo.
Personal or experimental MCP serverUser scope (~/.claude.json). Never the committed .mcp.json.
Standard integration (GitLab, Jira, GitHub)Use a community server; build custom only for team-specific workflows.

Path tell: ~/… = only you. A path in the repo = the team, once committed (except CLAUDE.local.md, which you add to .gitignore).
