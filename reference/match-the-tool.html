Match the tool

Ask what the stem names. Small job → the light tool. The heavier tool only when the stem names what it's built for.

JobLight tool (small, named job)Heavier tool is right when the stem names…
Change code (3.4)Direct execution, with a test. One function, a clear stack trace, a diff you can say in one sentence.Plan mode: many files (45+), several valid approaches, an architectural choice, unfamiliar code. Then execute the plan directly.
Find your way (2.5)Grep for the entry point (route, function, error message), Read it, follow the calls.Explore subagent: a long, verbose discovery phase with no known start, where the output would fill the main context. Never "read every file up front".
Give context (3.1, 3.3)@file in this session's prompt: needed once..claude/rules/ with paths: needed whenever matching files are read or edited. CLAUDE.md: needed in every session.

Words that don't change the answer

Stem wordWhat to do with it
"business-critical", "regulated", "production"Check the change harder (add the test). Don't add a planning phase to a one-line fix.
"220 files", "large codebase"Irrelevant if a starting point is named. Trace one path.
"a teammate suggests…"Setup, not a fact about the task.
a subagent for bulk readingChanges where the reading happens, not how much.
