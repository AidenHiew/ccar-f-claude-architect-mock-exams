Built-in tools

Pick the tool by what you already know about the target.

One job each

Glob
Matches file paths by name or extension pattern, e.g. **/*.test.tsx. Never opens a file.
Grep
Matches lines inside files: function names, callers, error messages, imports. Can be scoped to files with a glob or a language type.
Read
Loads a whole file (or a line range). Every Read uses context.
Write
Creates a file or overwrites the whole of it.
Edit
Targeted change, anchored on a unique text match.
Bash
Runs commands: tests, builds, git.

Decision test

know the name
→ Glob
know some text
→ Grep
both
→ Grep with a file filter (one call, not Glob then Read each)
Edit anchor not unique
→ Read the whole file, then Write it back

Exploration loop (context-limited)

1 · Grep
for a concrete entry point: route, error string, function.
2 · Read
only the hits.
3 · follow
imports and calls, then Grep the next name.
wrappers
list every exported name first, then Grep each one (re-exports rename things).
Distractor shapes. "Read all files up front" (complete but blows the context) · Glob used to find callers (a name match for a content question) · Grep only the original name through a wrapper (misses aliases) · an MCP tool ignored in favour of Grep → improve the MCP tool's description (2.4).
