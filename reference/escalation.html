Escalation triggers

Run this list on every escalation question. If no trigger fires, do not escalate.

Escalate — three triggers

1 · explicit
Customer asks for a human → escalate immediately, no investigation first.
2 · policy gap
Policy is silent or ambiguous on the request → escalate; the agent does not adjudicate it.
3 · stuck
Agent cannot make meaningful progress → escalate. (Hard-but-doable ≠ stuck.)

Do not escalate — the two baits

emotion
Frustration/sentiment is not a trigger. Simple in-policy request → acknowledge & resolve; escalate only if they then reiterate wanting a human.
confidence
A low self-reported confidence score is poorly calibrated → not an escalation signal.

Adjacent rule

ambiguity
Multiple customer matches → ask for another identifier. Never guess heuristically; not an escalation.

Exam tells

"put me through / speak to someone" → escalate now. "policy covers X but is silent on Y", Y is asked → escalate. Any option where the agent approves, declines, or gathers-info-then-decides a case the policy never addressed is the wrong-problem distractor. "angry / frustrated / upset" with a routine request → resolve, don't escalate.
